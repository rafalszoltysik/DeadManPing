# Launch Checklist

## 📋 Pre-Launch Checklist (2-3 tygodnie przed)

### **Content Preparation:**
- [ ] Wszystkie posty przygotowane (kopiuj-wklej gotowe)
- [ ] Product Hunt listing przygotowany (ale nie live)
- [ ] Obrazy do Product Hunt gotowe (min. 3)
- [ ] Tagline przygotowany (60 znaków)
- [ ] Opis przygotowany (500 znaków)
- [ ] First comment przygotowany
- [ ] Launch tags wybrane (3 tagi)
- [ ] Shoutouts przygotowane (3 produkty)

### **Platform Setup:**
- [ ] X (Twitter) konto gotowe
- [ ] Threads konto gotowe
- [ ] Reddit konto gotowe (jeśli używasz)
- [ ] Profile zaktualizowane (bio, linki)
- [ ] Link do Product Hunt w bio (po launch)

### **Assets:**
- [ ] Screenshot dashboardu
- [ ] Screenshot formularza monitora
- [ ] Code example screenshot
- [ ] Hero image (social preview)
- [ ] Logo/ikony gotowe

### **Content Assets:**
- [ ] Blog posty gotowe (jeśli planujesz)
- [ ] GitHub examples zaktualizowane
- [ ] Linki sprawdzone
- [ ] Wszystkie URL-e działają

### **Community Building:**
- [ ] Lista supporterów przygotowana (jeśli masz)
- [ ] Wiadomości do supporterów przygotowane
- [ ] Social media followers budowane

---

## 📋 Week Before Launch Checklist

### **Content:**
- [ ] Daily posty zaplanowane
- [ ] Launch day posty przygotowane
- [ ] Reddit posty przygotowane
- [ ] Wszystkie linki sprawdzone

### **Product Hunt:**
- [ ] Listing gotowy (wszystkie sekcje wypełnione)
- [ ] Obrazy uploadowane
- [ ] Opis finalny
- [ ] First comment gotowy
- [ ] Shoutouts dodane
- [ ] **NIE** klikaj "Make it live" jeszcze!

### **Social Media:**
- [ ] Posty zaplanowane (możesz użyć scheduler)
- [ ] Launch day posty gotowe (kopiuj-wklej)
- [ ] Hashtagi przygotowane
- [ ] Linki sprawdzone

### **Technical:**
- [ ] Strona główna działa
- [ ] Wszystkie linki działają
- [ ] Free trial działa
- [ ] Sign up działa
- [ ] Dashboard działa

---

## 📋 Launch Day Checklist

### **00:00 PST (09:00 CET) - Final Check:**
- [ ] Product Hunt listing gotowy
- [ ] Wszystkie posty gotowe (kopiuj-wklej)
- [ ] Linki sprawdzone
- [ ] Alarm ustawiony (00:01 PST)

### **00:01 PST (09:01 CET) - Launch:**
- [ ] Kliknij "Make it live" na Product Hunt
- [ ] Sprawdź, czy wszystko wyświetla się poprawnie
- [ ] Zweryfikuj linki, obrazy, opis
- [ ] Skopiuj link do Product Hunt

### **00:05 PST (09:05 CET) - Social Media:**
- [ ] Post na X (Twitter) - pin
- [ ] Post na Threads
- [ ] Retweet własny post (po 10 min)

### **00:10 PST (09:10 CET) - Follow-up:**
- [ ] Follow-up thread na X
- [ ] Post na Reddit (1-2 subreddity)
- [ ] Sprawdź komentarze

### **00:30 PST (09:30 CET) - Engagement:**
- [ ] Odpowiedz na komentarze na Product Hunt
- [ ] Odpowiedz na komentarze na social media
- [ ] Dziękuj za upvotes

### **Co 2-3 godziny:**
- [ ] Update post na X
- [ ] Sprawdź komentarze
- [ ] Dziękuj za upvotes
- [ ] Engage z innymi

### **Przez cały dzień:**
- [ ] Bądź aktywny w komentarzach
- [ ] Odpowiadaj szybko (w ciągu 1-2 godzin)
- [ ] Dziękuj za wsparcie
- [ ] Share posty innych (jeśli wspomną o tobie)

---

## 📋 Post-Launch Checklist

### **Dzień po launch:**
- [ ] Podsumuj wyniki
- [ ] Dziękuj wszystkim supporterom
- [ ] Follow-up post na social media
- [ ] Analiza metryk

### **Tydzień po launch:**
- [ ] Follow-up z użytkownikami
- [ ] Zbierz feedback
- [ ] Dziękuj za wsparcie
- [ ] Kontynuuj budowanie społeczności

## 🎯 Metryki do śledzenia

### **Product Hunt:**
- [ ] Upvotes (cel: 100+ w pierwszych 2 godzinach)
- [ ] Comments (cel: 50+)
- [ ] Views (cel: 1000+)
- [ ] Ranking (cel: Top 5)

### **Social Media:**
- [ ] Followers (X, Threads)
- [ ] Engagement rate
- [ ] Link clicks
- [ ] Retweets/shares

### **Website:**
- [ ] Sign-ups
- [ ] Free trial starts
- [ ] Conversions
- [ ] Traffic sources

## 💡 Tips & Reminders

### **Przed launch:**
- ✅ Nie spamuj - jakość > ilość
- ✅ Buduj społeczność wcześniej
- ✅ Wykorzystaj blog i GitHub
- ✅ Przygotuj wszystko z wyprzedzeniem

### **Launch day:**
- ✅ Bądź aktywny - odpowiadaj szybko
- ✅ Dziękuj za każdy upvote
- ✅ Engage z innymi produktami na PH
- ✅ Nie spamuj - postuj strategicznie

### **Po launch:**
- ✅ Podsumuj wyniki
- ✅ Dziękuj wszystkim
- ✅ Follow-up z użytkownikami
- ✅ Kontynuuj budowanie społeczności

---

## 🚨 Common Mistakes to Avoid

- ❌ **Spamowanie** - nie postuj za często
- ❌ **Ignorowanie komentarzy** - odpowiadaj szybko
- ❌ **Prośba o upvotes** - na Reddit to przełamuje rules
- ❌ **Zapominanie o engagement** - bądź aktywny
- ❌ **Brak przygotowania** - przygotuj wszystko z wyprzedzeniem
